# Stelchar Aluminium

A responsive, single-page website for Stelchar Aluminium built with plain HTML, CSS and JavaScript. No frameworks, build step or external font dependencies are required.

## Preview

Open `index.html` directly, or serve the directory locally:

```sh
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Content notes

- Project images are illustrative concept visuals, not verified photographs of completed Stelchar projects.
- The reviews section intentionally contains no invented testimonials or ratings. Add genuine Google review text to `verifiedGoogleReviews` in `script.js`; the carousel is configured for three reviews at a time and a five-second rotation.
- Quote links and the contact form open a prepared WhatsApp message to `+254 723 732152`.
